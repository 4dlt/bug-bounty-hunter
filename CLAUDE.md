# bug-bounty-hunter

## Agent skills

### Issue tracker

GitHub Issues at `github.com/4dlt/bug-bounty-hunter` via the `gh` CLI. PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical defaults — `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — one `CONTEXT.md` at root, ADRs under `docs/adr/`. See `docs/agents/domain.md`.
